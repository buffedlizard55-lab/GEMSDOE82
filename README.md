## Why H33-2-B2 scored 0.2778 — and how H82-3 improves on it

Masked mass is pure cost: the scorer masks catalogue faults, so dots within
kernel reach only of masked truth pay `α=0.2` and earn ~0. The
D2.8→R1→B2 chain is pure waste deletion (byte-verified pixel-exact:
`D2.8 & dist>1 == R1`, `R1 & dist>2 == B2`), gaining +0.0108/+0.0070
owner-reported per step; the live-anchored inversion (T≈5,069, K≈13,300)
cross-checks to 0.2%. Furthermore, because the 300 m triangular kernel
`k(d) = max(1 - d/3, 0)` vanishes at `d >= 3.0 px`, 100% of H33-2-B2's
near-catalogue tip credit resides in the 1,611 dots at `2.0 < d2c < 3.0 px`.
Lane H82-3 protects those 1,611 near-tip dots, prunes 14,654 uncorroborated
`d2c >= 3.0` dots using coverage-aware multi-physics corroboration (without
touching SGMC proxy truth), and adds 12,000 high-corroboration far-field dots
strictly `> 3.0 px` from all 6 registry rasters — improving all four holdout
instruments (`SGMC-FAR` +0.0298, `SGMC-MID` +0.0224, `SGMC-RAW` +0.0219,
`CAT-HIDDEN` +0.00014) while passing the strict full-mask duplicate guard.
Details: [`knowledge/02_why_h33_scored_02778.md`](knowledge/02_why_h33_scored_02778.md).
