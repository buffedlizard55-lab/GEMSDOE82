## Why H33-2-B2 scored 0.2778 (one paragraph; full PhD analysis in `knowledge/`)

Masked mass is pure cost: the scorer masks catalogue faults, so dots within
kernel reach only of masked truth pay `α=0.2` and earn ~0. The
D2.8→R1→B2 chain is pure waste deletion (byte-verified pixel-exact:
`D2.8 & dist>1 == R1`, `R1 & dist>2 == B2`), gaining +0.0108/+0.0070
owner-reported per step; the live-anchored inversion (T≈5,069, K≈13,300)
cross-checks to 0.2%. Blanket B=3 is break-even (d==3 dots can still earn live
credit) — so lane H82-2 goes *selective*: corroborated retention + screened
additions. Details: [`knowledge/02_why_h33_scored_02778.md`](knowledge/02_why_h33_scored_02778.md).
