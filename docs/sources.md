## Evidence classes used in this repository

- **OFFICIAL** — directly stated by an organizer or official government source linked above.
- **MEASURED** — recomputed from local, hash-pinned bytes. There are no such raster measurements in this checkout yet.
- **HOLDOUT-DTI** — a result from the pinned shared evaluator, accompanied by evaluator version, withheld-positive count and 95% CI.
- **ORGANIZER-CONFIRMED** — copied from a DrivenData submission-page receipt for the named artifact. A public leaderboard row is reported separately as external context and is not a receipt for our file.
- **BLOCKED / UNVERIFIED** — source or claim named, but data bytes, receipt, coverage, alignment or reproducibility are missing.

## Source-citation practice

Link every scientific and engineering claim to its primary source. A URL being reachable does not prove that a raster covers the AOI, that it has a suitable resolution, that the license permits use in the contest, or that it improves DTI. Record those as separate checks in the run card.
