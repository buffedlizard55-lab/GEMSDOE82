Official task contract

A valid submission is more than a map image

The organizer specifies a single-band float32 GeoTIFF on the competition grid (EPSG:32611, 100 m), matching the supplied bounds/template. Predictions must be in [0,1]; the official page says data outside the bounds should be null/NaN. The scoring metric is distance-weighted Tversky with α=0.2, β=0.8, and a 300 m triangular kernel.

Source: DrivenData problem description — metric and submission format. The file-level validator has not run because there is no sample template or candidate TIFF.

Before any candidate is emitted, the required pipeline hides whole fault segments, derives catalogue-based features from visible faults only, masks visible faults pixel-exactly, runs a feature-by-feature leakage canary, and compares the final surface against the registry. See the pre-registered validation gates.
