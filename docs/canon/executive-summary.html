Before the upload

Required project-side checks

  1. Read the run card. Confirm the current experiment has a `promote` verdict from the separate selector. A `negative`, `blocked`, or missing card is not approval to upload.
  2. Download only the exact validated file. The card must contain the file name, SHA-256, method and a validator receipt. Do not substitute a file with a similar name or use a previous submission raster.
  3. Run the shared writer and validator. Compare CRS, dimensions, transform, resolution, band count and data mask against the official sample template. Confirm float32 and valid predictions in [0,1]. Confirm the footprint has no NaN and no nodata sentinel inside it. Respect the organizer’s outside-bounds rule and confirm the portal handles the chosen outside-fill representation.
  4. Review uniqueness and evidence. Check the final raster against all registered rasters. Confirm no duplicate threshold was crossed and that the hide-and-recover result includes the evaluator version, withheld-positive count and 95% CI.

DrivenData upload

Step-by-step submission form

  1. Sign in to the competition. Open the official GEMS Prize page and sign in with your existing DrivenData account. The data page redirects unauthenticated visitors to login; this project does not access or store credentials.
  2. Open the submission form. Choose the competition’s “New submission” action. Check the submission cap and deadline shown on the logged-in page at that time; neither is hard-coded here.
  3. Choose the file. Select the single-band GeoTIFF. The project request quotes the logged-in submission form as accepting a single-band GeoTIFF or a ZIP containing one GeoTIFF; the public problem page specifies a GeoTIFF. Verify the logged-in form at upload time and prefer the `.tif` directly. If using ZIP, include exactly one `.tif` and no unrelated files. The current project has no file to select.
  4. Enter a unique name and a short note. Give the entry a team-specific name that is not reused. In the optional note, describe the one method change and its evidence status; keep the note at or below 140 characters. Never label a projection as a score.
  5. Submit and save the receipt. After the organizer accepts the file, save the submission-page receipt (submission ID, exact filename, timestamp, and displayed score/status) with the raster SHA-256 in the project registry. Only a receipt can establish an `ORGANIZER-CONFIRMED` result for that artifact.
