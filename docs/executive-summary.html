Why the range error is prevented

Input sanitation

Feature sentinels below −1e30 are converted to missing values only inside feature calculations. They are never written to the output.

Fail-closed output

The writer refuses NaN, infinity, values outside [0, 1], wrong metadata, or positive mass outside the sample footprint. It does not silently clip or repair a prediction.

Independent re-read

The receipt is generated after reopening the staged GeoTIFF, then atomically renaming it. The receipt says whether every check passed.

The official problem page specifies EPSG:32611, 100 m resolution, matching bounds, one float32 layer, probabilities in [0, 1], and null/NaN outside the bounds. This artifact uses all-finite zeros outside the footprint to address the observed range-validator failure; follow any current organizer instruction if it differs.
