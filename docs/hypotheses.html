Experiment accounting

Exactly three runs

H82-A, H82-B, and H82-C were executed at a matched 37654-dot budget. The second pass corrected an exact-tie bug in percentile clipping before the final recorded run; the corrected receipt is the only result retained.

Canaries

Each used raw layer and each candidate surface was tested alone. No H82-B canary exceeded the leakage stop threshold. The full machine-readable values are in experiments.json.

Promotion rule

The best of these three was packaged, but no automatic promotion occurred. The separate selector must compare a current incumbent under the same evaluator and review the complete registry.

Prior-lane audit

The novelty statement is a method audit, not a claim that all private code is known. The sibling sites show earlier families including catalogue buffers, dotted ridge thinning, DEM scarp/curvature, Euler/tip/relay operators, multi-physics orientation votes, conductivity breach, radiometric fusion, supervised HGB, and exact submodular allocation. H82-B was intentionally defined around signed Laplacian polarity dispersion before code was written.
